# Sanjeev Kumar — Portfolio

Premium single-hero Next.js portfolio with an interactive liquid-glass reveal.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build for static hosting

```bash
npm run build
```

The static site is generated in `out/`.

## Images

The approved desktop base and reveal portraits are stored in:

- `public/images/Base_image_desktop.png`
- `public/images/Reveal_image_desktop.png`

The current project intentionally does not invent mobile portrait assets; the supplied approved desktop pair is used responsively.
